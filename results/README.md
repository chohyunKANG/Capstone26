## 3. 해석

- 사후 적용, 학습 단계 적용, κ 16·64, 지각 손실 유무 모두에서 **마스킹은 같은 명료도의 균일 축소보다 보호가 약했다.** Enkidu의 보호 성분은 잘 들리는 약한 영역(무음, 스펙트럼 골짜기)에 몰려 있어서, 들리는 부분을 빼면 보호도 함께 빠진다.
- 복제 단계에서도 같은 결론이다. v1은 명료도를 크게 올렸지만(STOI 0.68 → 0.87) 정화 후 보호가 사라졌다. 팀 포스터에서 세 기법(SceneGuard, SafeSpeech, Enkidu)이 보인 **사용성과 정화 저항성의 trade-off가 개조 모델에서도 재현**됐다.
- 아직 확인하지 않은 것: 같은 STOI의 **균일 축소본을 정화·복제까지** 보내면 잔존이 남는지. 남으면 잔존을 없앤 원인은 마스킹 배치 방식이고, 안 남으면 섭동 진폭 자체다.

## 4. 공개 코드를 읽으며 발견한 점 (`core/enkidu.py`)

- 논문 Algorithm 1의 시간 영역 증강(가산 노이즈, 시간 이동, 볼륨)은 **실행되지 않는다.** `__init__`의 `self.augmentation = augmentation`이 같은 이름의 메서드를 덮어쓰고, `forward()`도 그 메서드를 부르지 않는다.
- 학습 중 `add_noise`는 `random_offset=False`로 호출된다. 실제로 켜진 학습 증강은 프레임 마스킹(`mask_ratio=0.3`) 하나다.
- `hop_length` 기본값은 512라 30프레임 패치는 약 0.96초다.
- 손실의 지각 항(λ=0.1)은 꺼도 결과가 같았다(위 표의 κ=16 두 행).
- 학습 손실은 `1 − MSE(원본 임베딩, 보호 임베딩)`이다. 임베딩 거리를 키우는 방향이다.
