## 3. 해석

- **정화를 버티려면 섭동의 크기가 필요하다.** 원본 패치를 모양 그대로 크기만 줄인 대조군도 잔존이 0이었다. STOI 0.87 수준의 잡음형 섭동은 모양(v1 마스킹), 학습 대상(v2 XTTS), 단순 축소(대조군) 어느 쪽이든 De-AntiFake 정화 후 보호가 남지 않았다. 정화를 버틴 것은 크고 시끄러운 원본 Enkidu(STOI 0.68)뿐이다. 팀 포스터에서 본 사용성–정화 저항성 trade-off가 개조 모델과 대조군에서도 재현됐다.
- **같은 사용성에서 정화 전 보호는 v2 > 대조군 > v1이다.** v2는 단순 축소보다 ECAPA 2배, Resemblyzer 3배 강하다(채점 모델 둘 다 v2 학습과 무관). 공격자가 정화를 쓰지 않는 상황에서는 복제 모델을 겨냥한 학습이 실질적인 개선이다. v1(마스킹)은 단순 축소보다도 약해, 입력 단계 결과가 복제 단계에서도 확인됐다.
- **보호가 약하면 정화가 오히려 손해다.** 대조군·v1에서는 정화기 자체 손상(C1−C4 = 0.177)이 보호 효과보다 커서 C3가 C2보다 낮거나 비슷하다.
- Resemblyzer에서 대조군·v2의 C4−C3가 −0.012로 작게 음수였다. 크기가 작아 해석하지 않는다.
- **다음 방향:** 잡음이 아닌, 정화기가 지키는 "자연스러운 음성" 안에 보호를 넣는 방식(음색 변형 등). 다만 사람이 듣기에 원래 목소리로 들리는지를 따로 평가해야 한다.

## 4. 공개 코드를 읽으며 발견한 점 (`core/enkidu.py`)

- 논문 Algorithm 1의 시간 영역 증강(가산 노이즈, 시간 이동, 볼륨)은 **실행되지 않는다.** `__init__`의 `self.augmentation = augmentation`이 같은 이름의 메서드를 덮어쓰고, `forward()`도 그 메서드를 부르지 않는다.
- 학습 중 `add_noise`는 `random_offset=False`로 호출된다. 실제로 켜진 학습 증강은 프레임 마스킹(`mask_ratio=0.3`) 하나다.
- `hop_length` 기본값은 512라 30프레임 패치는 약 0.96초다.
- 손실의 지각 항(λ=0.1)은 꺼도 결과가 같았다(위 표의 κ=16 두 행).
- 학습 손실은 `1 − MSE(원본 임베딩, 보호 임베딩)`이다. 임베딩 거리를 키우는 방향이다.
